## Green semantics

`ExitBootServices` returns success. It proves only:

- EBS succeeded;
- `DarwinEnter` started;
- execution reached the loader handoff assembly.

## Interpretation

The previous three-stage probe already proved:

- XNU `_start`;
- execution to the `SCTLR_EL1` write;
- post-MMU execution to `common_start+0xE0`.

The current source and disassembly show:

```text
common_start returns to _arm_init
_arm_init entry             0xFFFFFFF0079BF074
call _arm_vm_init           0xFFFFFFF0079BF7E4
_arm_vm_init entry          0xFFFFFFF0073EA0F4
```

If `_arm_vm_init` had been reached in the current probe, it would have reset
immediately. No reset was observed, so the conservative conclusion is that
execution did not reach `_arm_vm_init`.

The first unresolved boundary is now the return from `common_start` into
`_arm_init`, or a failure between `_arm_init` entry and its `_arm_vm_init`
call. No DarwinBoot change is justified by this result.
